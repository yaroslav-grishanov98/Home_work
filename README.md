### card_number_generator(start, stop)
Функция генерирует отформатированные номера карт в заданном диапазоне.

**Тесты:**

* Проверяет генерацию номеров карт в заданном диапазоне.
* Тестирует генерацию с разными диапазонами чисел.
* Проверяет случай, когда start и stop равны (один номер в диапазоне).
* Проверяет, что функция правильно обрабатывает начальное значение 0.
* Использует @pytest.fixture для предоставления списка сгенерированных номеров карт.


### Функции filter_by_currency
Эта функция принимает список транзакций (словари) и строку с кодом валюты. Выдает генератор, который последовательно возвращает транзакции, соответствующие заданному коду валюты.

**Тесты:**

* Проверяется, что функция возвращает 2 транзакции с валютой "USD".
* Проверяется, что функция возвращает 0 транзакций для валюты "GBP" (которая не присутствует в списке).
* Проверяется, что функция возвращает 0 транзакций для пустого списка.
* Проверяется, что функция возвращает 0 транзакций, когда в списке есть транзакция с валютой "EUR".
* Проверяется, что функция возвращает 1 транзакцию с валютой "EUR".


### Функции transaction_descriptions
Эта функция принимает список транзакций и возвращает генератор с описанием каждой транзакции. Если описание отсутствует, возвращает пробел.

**Тесты:**

* Проверяется, что функция возвращает правильные описания для заданных транзакций.
* Проверяется, что функция возвращает пустой список для пустого ввода.
* Проверяется, как функция справляется с транзакциями, в которых отсутствуют описания. Ожидается, что пустая строка будет возвращена вместо недостающего описания.


### Функции card_number_generator
Эта функция генерирует номера банковских карт в формате XXXX XXXX XXXX XXXX, начиная с указанного числа до конца.

**Тесты:**

* Проверяется, что функция генерирует номера карт от 1 до 5 в правильном формате.
* Проверяется, что функция правильно возвращает номер карты для диапазона от 1 до 1.
* Проверяется, что для большого диапазона от 1 до 9999 функция генерирует 9999 номеров карт, и все номера имеют длину 16 символов без пробелов.
* Проверяется, что функция возвращает пустой список, если начальный номер больше конечного.
* Проверяется, что функция правильно генерирует номер карты для диапазона от 0 до 0.
